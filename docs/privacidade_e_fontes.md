# ETL – Dados do Vestibular UERJ

## Fonte dos dados

Os dados utilizados nesta análise foram obtidos a partir dos documentos
publicamente disponibilizados pela Universidade do Estado do Rio de Janeiro
(UERJ) em seu portal oficial do Vestibular:

🔗 https://www.vestibular.uerj.br/?page_id=8456

Os documentos foram utilizados para fins acadêmicos e de estudo de
Engenharia e Análise de Dados.

## Privacidade e proteção de dados

Os documentos de origem podem conter informações pessoais de candidatos.
Durante o processo de ETL, essas informações são tratadas de acordo com o
princípio de minimização de dados.

Informações como nome e número de inscrição não são necessárias para as
análises estatísticas propostas neste projeto e, portanto, não devem ser
expostas no dataset analítico final.

As análises são realizadas de forma agregada, considerando variáveis como
ano, curso, turno, unidade, modalidade de ingresso, concorrência e
desempenho.

O projeto não tem como finalidade identificar candidatos individualmente.
